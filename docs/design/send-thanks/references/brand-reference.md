# Email, thanks brand reference

## Source and direction

Source system: Website Thanks brand tokens and the selected companion wordmark reference 1a. The bold wordmark uses a tomato comma. Email, thanks keeps that treatment and adds the comma only icon from the Claude Design export.

The selected dashboard direction is **2b Workbench** from the Claude Design project. The dashboard and five 390 pixel phone views are stored alongside this reference. The exported TSX and CSS are the implementation source for the main application shell.

## Tokens

| Token | Value | Use |
| --- | --- | --- |
| Paper | `#F4EEE3` | Main dashboard background |
| Chalk | `#FBF9F5` | Cards and navigation surfaces |
| Ink | `#1C1916` | Main text and heavy outlines |
| Graphite | `#3D3832` | Supporting text |
| Tomato | `#FF5A36` | Primary action and comma |
| Honey | `#F7D56E` | Active navigation and emphasis |
| Basil | `#2E6B4B` | Verified state |
| Line | `#E3DCD0` | Quiet separators |
| Pencil | `#6B6359` | Muted text |

Typography uses Schibsted Grotesk for the interface and a restrained system monospace for technical labels. The application bundles the variable Schibsted font locally from the Website Thanks brand font set.

## Guardrails

Keep the chunky friendly cards, tomato comma, cream paper surfaces, ink outlines, honey selection state and readable word labels. Status meaning must not rely on colour alone. The production dashboard must not imply that recipient delivery, bounce or complaint events are collected when only handoff status is stored.
